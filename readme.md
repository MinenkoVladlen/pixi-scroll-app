# Pixi Scroll App

A responsive scrollable list built with PixiJS and TypeScript.

## Features

- Full-screen PixiJS canvas
- Mouse and touch drag scrolling
- Mouse wheel scrolling
- Inertial scrolling based on pointer velocity
- Vertical scrolling in portrait orientation
- Horizontal scrolling in landscape orientation
- Scroll position preservation on resize and orientation change
- Fullscreen mode toggle

## Tech Stack

- TypeScript
- PixiJS
- Vite

## Run locally

```bash
npm install
npm run dev
```
